# 显示器布局配置

主副机共用一张逻辑桌面。每块屏幕只配置物理分辨率 `width` / `height`、缩放倍数 `scale` 和全局逻辑坐标 `x` / `y`。不配置上下左右连接、边缘百分比或百分比区间。

```json
{
  "local_display": {"width": 2560, "height": 1440, "scale": 1, "x": 0, "y": 0},
  "remote_display": {"width": 1920, "height": 1080, "scale": 1.5, "x": -1280, "y": 40}
}
```

这里副机的逻辑尺寸为 `1920 / 1.5 × 1080 / 1.5 = 1280 × 720`，占据全局 `(-1280, 40)` 到 `(0, 760)`。它位于主屏左边，下移 40 个逻辑像素。窗口使用同一套坐标，捕获纹理在接收端按副机缩放显示。

`scale: 1.5` 就是 Hyprland 的 1.5 倍，不是百分比区间，也不是每像素的逆比例。支持 0.125 到 8、最多三位小数。内部用整数比例换算到千分之一逻辑像素，避免将 1.5 的倒数近似为 667。物理分辨率必须在每轴 1 到 32768 像素范围内。

允许负坐标、错位、上下排列、对角排列和间隙；不允许显示矩形重叠。有间隙时不会把指针自动传送到另一边，窗口仍必须实际进入目标矩形才能被接纳。只在同一边缘真实重合的部分存在连续的跨屏路径。

## 生成当前 Linux / Windows 配置

```sh
tools/desktop-drag-pair.sh prepare \
  --dir /absolute/private/viewflow-pair \
  --monitor DP-4 --linux-ip 172.16.105.62 \
  --windows-host WindowsVM --windows-ip 172.16.105.70 \
  --windows-resolution 1920x1080 --windows-scale 1.5 \
  --windows-position -1280x40
```

主屏配置从选定的 Hyprland 输出读取；副屏坐标必须显式提供。启动器按副屏的物理分辨率、缩放和坐标创建虚拟输出，校验实际输出尺寸后再捕获窗口。改变已有配置中的布局后，需要同时更新两端并重启会话。

生成的 `send.json` 在 `desktop.local_display` / `desktop.remote_display` 中保存上述配置。`receive.json` 在 `desktop.display` 中保存同一个副屏配置。接收端另外提供 `desktop.native_x` / `desktop.native_y`（默认 0），用于选定 Windows 自身桌面上的物理像素起点；它们不改变主副机的全局布局。生成工具对应的可选参数为 `--native-x` / `--native-y`。

旧的 `local_viewport` / `remote_viewport`、接收端 `scale_millidip_per_pixel` 和逆比例 `--windows-scale 1000` 不再是有效配置。请重新生成配对配置或迁移到上面的字段；不要混用新旧两端程序。

此布局负责桌面位置与跨屏归属。Deskflow sidecar 若用于底层输入，其内部事件枚举不再作为产品的显示器布局配置来源。

## 同一连接上的物理鼠标交接

桌面启动器在创建副屏、重新读取并验证其分辨率/缩放/坐标后，将本次输出 ID 写入临时生效配置的 `pointer.cursor_monitor_id`。配对配置不保存可跨运行复用的输出 ID；手工运行且未设置此字段时，不开启 Linux 物理输入抓取。接收端需要 `desktop` 配置，才能将全局逻辑指针坐标换算为 Windows 原生物理像素。

抓取只跨明确拥有的副屏矩形与本地矩形的真实共享边；已有其他 headless 输出仍属于本地。按键或鼠标按钮尚未释放时不启动抓取；若拖窗已经把指针带入副屏，释放后再次移动可从当前全局坐标交接。Linux `Ctrl+Alt+Escape` 是原生紧急归还操作。

交接使用已有认证连接和同一原生输入套接字。进入时建立输入租约并等待原生抓取回执，每个 Windows 输入事件保留原始期限和应用回执；返回时确认 Windows 释放租约，再确认 Linux 原生释放。反向代理输入只在本次显式抓取租约授权下允许；本地接管、未确认清理、旧 generation 和过期事件不能恢复旧窗口授权。断连、设备丢失、会话锁定或副屏拓扑变更会触发原生释放。

这些是已接入的实现路径，实际混合操作及高轮询率鼠标的持续时限仍需配对设备验收；不能将原生回执等同于应用完成处理或像素已呈现。
