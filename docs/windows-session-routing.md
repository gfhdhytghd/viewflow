# Windows 登录前后的输入路由

`desktop-autostart-linux.py` 可通过 `--fallback-config` 和 `--fallback-peer` 同时管理窗口共享与预登录输入，两个配置必须指向同一台已识别的 Windows 主机，并使用相同显示几何。

- 启动时先使用预登录输入，不等待 Windows 用户登录或虚拟显示 DPI 查询。
- 每隔约三秒只读查询登录界面、用户桌面和媒体 UDP 监听状态。锁屏、注销或媒体进程退出时回退到输入通路。
- 连续两次确认桌面与接收端就绪后恢复共享；共享进程异常退出后至少等待三十秒再尝试，避免反复抢占输入通路。
- SSH 查询失败视为未知，不关闭当前连接。恢复共享前的配置和 DPI 准备在输入进程仍然运行时完成。
- 切换仅替换同一路由的子进程，不重载捕获插件、不切换 HDMI、不修改 Mac 路由，也不合成输入或焦点事件。正常退出负责释放原连接持有的输入状态。

部署示例见 `deploy/linux/viewflow-windows-session.conf`，安装到 `viewflow-desktop.service.d/99-windows-session.conf`，保留原服务的启动设置。未指定回退参数时，启动器保持原来的单通路行为。

2026-09-14 已在本机启用，使用现有运行二进制，未部署待验收的活动调度包。策略测试覆盖登录、锁屏、查询失败、接收端退出及重试退避；当前 Windows 登录界面下的输入连接已建立。实际解锁后的完整自动切换仍待用户操作验证。
