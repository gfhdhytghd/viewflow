# Gaussian 近似与降采样

用户已允许视觉相近的低成本模糊。这组试验在 Windows Intel 32902/32103 上，对同一 3840×2160 合成图进行离屏 GPU 测量；没有窗口、输入或真实背景抓取。所有数字仅代表该图与该实现，不能换算为整条 Viewflow 链路的收益。

每次试验五种模式，正序/逆序两个区块，每个模式各 50 次，剔除每段前 10 次，共 80 个有效 GPU 时间戳样本。源码、编译方法、原始 CSV、完整 BGRA gzip、PNG 和进程/哈希状态均已保存。

| 方法 | GPU 中位 ms | 相对 Balanced 的 RGB 平均差（0–255） | 最大差 |
|---|---:|---:|---:|
| Balanced | 3.399 | 0 | 0 |
| 1/4 线性降采样 + SPEED | 2.085 | 2.139 | 36 |
| 1/4 多采样预滤波 + SPEED | 2.144 | 0.504 | 5 |
| 1/8 多采样预滤波 + SPEED | 1.810 | 0.574 | 10 |
| 1/4 各向异性预滤波 + SPEED | 5.320 | 0.440 | 6 |

表格取自 [预滤波试验](prefilter/summary.json)。直接强降采样会丢失细线，多采样预滤波明显改善本测试图的结果。1/4 多采样方案约减少 1.26 ms GPU 时间，但并未部署或完成真实背景/整条链路性能验证。[首轮结果](summary.json)也保留了 SPEED、1/2、1/4、1/8 线性降采样的比较。

后续用户要求先解耦背景更新、再与 Hyprland 同步，因此当前推进的是 [30 Hz 后台背景缓冲](../background-buffer/README.md)。
