## 测量条件与限制

每轮源端 55 秒、桌面观察 30 秒。DD LastPresentTime 是所见桌面更新时间，计时上界包含跨机时钟不确定度，未证明是该帧第一次显示，更不是光子时间；不同标记/秒也不等同于物理显示 FPS。没有将两轮的最低延迟和最高更新率拼接为一个成绩。原生提交数仅描述程序工作量。

源 / Windows receiver / presenter / observer 与首版相同，原生直接绘制、背景缓存关闭，保留完整毛玻璃及源透明度；仅捕获插件调度不同。所有原生二进制和对应背景条纹像素验证见 [计时补丁后的基线](../hyperv-timer-enabled/README.md)。两轮普通对照和两轮候选共享本版同一插件，以私有 shim 选择原 grid 或 commit API。

ESRV 在四轮前后均为 PID 8628、High（128），CPU 时间保留在每轮原始 state 中。本实验未停止或修改它。嵌套环境与主桌面捕获频率实验不同，不能以跨实验最好成绩作因果比较。

## 验证和清理

相对 [首版提交唤醒](../commit-wakeup-hyperv/README.md)，只改动调度头文件和其测试。Release 构建及 8 项 CTest 通过，覆盖迟到静态 timer、不提前补采普通抖动提交、密集通知合并与速率限制、长停顿和整数饱和。GPU smoke 169 帧验证 native fence、双 FD、wire/身份、持有 A 时 B 继续、停止同组成员和同 ID 重建。GPU ownership、HCGR 及 renderer 未改。

嵌套合成器使用独立设备视图，仅允许 render/NVIDIA 节点，没有物理输入、seat 或 DRM 卡节点；自有输出相对已有输出 X/Y 均隔开至少 32768 像素。fixture 为空输入区域，Windows 测试窗口不激活且鼠标穿透，未注入输入。嵌套进程与临时输出已退出，原桌面插件和显示几何核对一致，Windows 诊断任务/进程/端口已清理，VDD 配置不变。
