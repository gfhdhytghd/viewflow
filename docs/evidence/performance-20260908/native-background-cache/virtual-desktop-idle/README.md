# 静止收缩后的虚拟桌面范围版本

停止移动 250 ms 后收缩临时移动余量；两次背景范围均回到 4154×2990，但仍大于实际 3840×2400 显示范围。用户随后明确要求缓存最大只到显示范围，下一版改为按实际显示器裁剪。此处结果不能代表后续裁剪版本。

开启仍有退步，未默认启用。15 Hz 尝试只完成关闭基线；开启时 launcher 的参数校验还只接受 0/1，提前退出 2，没有启动接收器。因此 **没有这版 15 Hz 性能结果**；保留失败状态，修复参数校验后再测后续版本。

3840×2400 内容、scale=2、128 像素半透明边缘，捕获为 3848×2408，正常 mTLS/H.264。实际观察输出为 3840×2400@60；枚举日志中的 6144×3456 是另一块显示器。背景范围错误来自取两块屏幕外接矩形，部分缓存位于显示器外。原始日志、分析及所有长尾在 runs，source 为实际编译输入；本版 105 个源文件与远端逐项哈希相同。无输入或焦点注入，HEADLESS-23/24 与自己的任务、进程均已清理。
