# Complete-frame publication from ordered bands

Refactored Frames publication into begin_write / Write::append / Write::finish. State1owns a slot throughout ordered band writes; finish requires exact full-height coverage before release-storestate2. Invalid/overflow/incomplete appends or repeatedfinish reject locally. Destruction of unfinished transaction returns slot tofree. Reader-held slots remain excluded. Existing publish appends one full frame, preserving rawBGRA reference ABI and slot count; mapping must outlive writer transaction, singleproducercontract unchanged.

Added meaningful tests: partial frame unavailable to acquire, incomplete finish rejected, excess rows rejected, exact assembled pixels, repeated finish rejected, abort with unrelated reader-held frame intact, exhausted slots returnempty and recover after cancel. Existing ownership,overwrite,paddedpitch,wire,concurrentintegrity tests passed on Linux and Windows. Windows WARP staging lease/reuse/crop/resize/adoption/fallback/fullpixel test passed.
