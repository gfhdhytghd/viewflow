Isolated compute conversion experiment after verified NV12 UAV capability. Both comparison arms allocate identical BGRA RTV/SRV and NV12 RTV/UAV textures, and only conversion dispatch changes. Shader uses BT.709 full-range RGB to limited-range NV12, averages each 2x2 block for chroma and writes Y/UV planes. Numerical equivalence and encoded image quality must be measured before integration; this is not assumed from the coefficients. Source dimensions are even in the bounded 6K probe.
