# Longer bounded transport observations

The fixture and launcher retain the standard 6K shader, waitable presentation queue, non-activating window and owned-process capture routing. Only fixture lifetime (130 seconds) and source observation watchdog (135 seconds) are extended. Two source files match their remote hashes; the build succeeds. Long-run helpers use source 120 seconds, Linux peer 117 seconds and observer 100 seconds within the existing peer diagnostic limit. The first 122-second Linux configuration was rejected before launching a Windows task; its failed method and complete cleanup are retained.

These longer observations exposed a delay increase hidden by the short paired runs. No metric threshold, warmup rule or observer geometry was changed. The immutable run records and copied executable hashes remain under transport/runs; this bundle is a measurement helper, not a deployed application change.
