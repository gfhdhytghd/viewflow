# 异步alpha＋编码器就绪检查：源端26.15FPS

承接`async-alpha`失败试跑，在atlas合成之前调用`HardwareEncoder::can_submit()`。它只读取现有异步编码器输入事件；暂时没有容量时继续轮询已有工作和接收输入，不反复提交清空／复制命令。alpha保持四槽异步精确读回，颜色和透明度以相同PTS合并并按序写出。

与同步基线相同的6K被动窗口、名义60Hz源配置，30秒后关闭输入。源程序及fixture均退出0，无watchdog，测试进程已全部结束；主程序未替换。Linux离线验证所有756条输出：完整6K、互补帧标记有效且无倒退、alpha为255、GL错误0。

这是一轮源端比较，未经过QUIC或Linux桌面实际呈现，**仍未达到完整链路6K30／60ms目标**。异步alpha的入队调用中位0.124ms，GPU完成等待中位14.159ms、CPU读出中位7.534ms、比较／编码中位3.185ms。CPU读出目前每次分配并初始化约21.2MB的vector，下一候选复用这块缓冲区。

AlphaPlane自身与初版完全相同，沿用已通过的GPU四槽精确像素测试。`source`是Windows编译快照；离线解码使用后来增加alpha检查的`method/record-probe-used.cpp`，二进制身份另行记录。所有实验代码仍在独立目录。
